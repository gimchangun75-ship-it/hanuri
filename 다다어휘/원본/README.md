# 다다어휘

**목적**: 다다어휘 교재의 원본과 초기 작업 파일을 보관합니다. 조판된 부교재는 [부교재](../부교재/README.md)에 있습니다.

**주요 내용**
- 차시별 원본 HWP: `1 헷갈리는 말 1차시.hwp`, `관용어_1차시.hwp`, `속담 왕보미 (1).hwp` 등
- `다다어휘 1호/`: 1호 한자어·헷갈리는 말 이미지 파일 (차시별 폴더)
- `문어잼/`: 문어잼 작업 이미지
- `다다어휘(워크북PDF)/1호/`: 1호 차시별 워크북 PDF
- `이미종(디자인)` 이름의 HWPX와 `.bak` 파일: 디자인 작업본과 백업

**최신본 찾는 법**: 디자인 최종본은 `../부교재/1호/디자인완성본` 등 `부교재`의 `디자인완성본` 폴더에 있습니다. 이 폴더의 `.bak` 파일은 구버전입니다.
