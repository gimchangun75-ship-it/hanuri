# 다다어휘(부교재)

**목적**: 다다어휘 부교재의 조판본을 호수와 차시별로 보관합니다.

**구성**
- `1호/`: 1호 차시별 파일 (헷갈리는 말, 어휘 충전, 드릴, 퀴즈, 교과서 한자어)
- `2호/`: 2호 차시별 파일 (관용어, 속담)
- `다다어휘 답안.pdf`: 답안지

**하위 폴더 (1호, 2호 공통)**
- `디자인완성본/`: 최종 디자인본 (HWPX, HTML, PDF). 작업기억카드 기준 현재 최종본 위치입니다.
- `디자인_한글파일모음/`: 디자인 HWPX 모음
- `제목없음.pdf`: 이름이 정해지지 않은 PDF. 용도 확인이 필요합니다.

**최신본 찾는 법**: 파일명에 `(디자인)`이 있는 HWPX가 조판 완성본입니다. `.html.bak`은 구버전입니다.

**주의**: 조판은 A4 한 장에 맞춥니다. 글자가 넘치지 않는지 확인합니다.
