다음 괄호에 알맞은 낱말을 골라 ○표 하세요. (1~20)
1 달빛이 세상을 환하게 ( 비추었다/비치었다 ).
2 호수에 ( 비친/비춘 ) 달이 환하다.
3 냇물에 발을 ( 담그고/담구고 ) 있었다.
4 농부가 땅을 갈아 ( 엎었다/업었다 ).
5 쓰레기 더미를 ( 헤치고/해치고 ) 잃어버린 물건을 찾았다.
6 쓰레기가 도시의 환경을 ( 헤치고/해치고 ) 있다.
7 탄산음료는 우리의 건강을 ( 헤친다/해친다 ).
8 선원들은 거친 파도를 ( 헤치고/해치고 ) 바다를 나아갔다.
9 대구를 ( 거쳐/걷혀 ) 부산으로 가자.
10 장마가 ( 거치자/걷히자 ) 불볕더위가 시작됐다.
11 큰 문제가 해결되었으니 이제 우리에게 ( 거칠/걷힐 ) 문제가 없다.
12 우리는 롯데자이언츠의 가을 야구를 ( 바란다/바랜다 ).
13 내 방에 햇빛이 들어와 책장에 꽂힌 책의 색이 ( 바랐다/바랬다 ).
14 아빠는 성공에 대한 ( 바람/바램 )이 간절하다.
15 도배를 하기 전 누렇게 ( 바란/바랜 ) 벽지를 뜯어냈다.
16 윗집에서 밤마다 세탁기 돌리는 소리가 ( 들여/들려 ) 잠을 잘 수가 없다.
17 학원에 ( 들렀다/들렸다 ) 집에 갔다.
18 박물관에 ( 들렀는데/들렸는데 ) 멀리서 ( 들르는/들리는 ) 바이올린 선율이 아름다웠다.
19 유니폼이 유난히 눈에 ( 띤다/띈다 ).
20 심청이의 목소리를 들은 심봉사의 눈이 번쩍 ( 띠었다/띄었다 ).

헷갈리는 말 ② — 정답 및 핵심 정리

Dada Vocabulary · Unit 02 · Teacher & Study Guide
• 핵심 어휘 정리 •
⊙
헤치다 / 해치다 : 헤치다(모인 것을 양옆으로 파거나 젖히다)  vs  해치다(손상을 입혀 망가지게 하다)
⊙
바라다 / 바래다 : 바라다(생각이나 희망대로 되기를 원하다)  vs  바래다(볕이나 습기로 색이 변하다)
⊙
껍질 / 껍데기 : 껍질(무르지 않은 겉 부분: 사과·포도·양파)  vs  껍데기(딱딱한 겉 부분: 조개·달걀·소라)
⊙
조리다 / 졸이다 : 조리다(양념이 배어들게 바특하게 끓이다)  vs  졸이다(국물을 증발시키다 / 마음을 태우다)
