1 자세를 ( 반드시/반듯이 ) 해라.
2 이 일은 ( 반드시/반듯이 ) 끝내야 한다.
3 도로가 비뚤지 않고 ( 반드시/반듯이 ) 나 있다.
4 버스의 좌석을 뒤로 ( 젖혔다/제쳤다 ).
5 나만 ( 젖혀/제쳐 ) 두고 편의점에 간다고?
6 산 ( 너머/넘어 ) 태양이 진다.
7 차가 중앙선을 ( 너머/넘어 ) 달려왔다.
8 이 영화는 열다섯 살이 ( 너머야/넘어야 ) 볼 수 있다.
9 고양이 똥을 밟아서 내가 ( 걸음/거름 )을 뗄 때마다 ( 걸음/거름 ) 냄새가 심하다.
10 밭에 ( 거름/걸음 )을 주었다.
11 형은 늦었다며 ( 거름/걸음 )을 재촉했다.
12 손에 양념을 ( 무치다/묻히다 ).
13 보물이 땅 속 깊숙이 ( 무쳐/묻혀 ) 있었다.
14 얼굴에 소스를 잔뜩 ( 무치면서/묻히면서 ) 먹고 있구나.
15 시금치 ( 무친/묻힌 ) 거 먹어도 되나요?
16 다리가 ( 저려서/절여서 ) 힘들다.
17 보약을 정성스레 ( 다렸다/달였다 ).
18 꿀에 ( 저린/절인 ) 인삼은 맛있다.
19 다리미로 옷을 ( 다렸다/달였다 ).
20 방에 불을 ( 때다/떼다 ).

헷갈리는 말 ① — 정답 및 핵심 정리

Dada Vocabulary · Unit 01 · Teacher & Study Guide
• 핵심 어휘 정리 •
⊙
반드시 / 반듯이 : 반드시(꼭, 틀림없이)  vs  반듯이(비뚤어지지 않고 바르게)
⊙
너머 / 넘어 : 너머(고개·산·담 같은 공간의 저쪽)  vs  넘어(경계나 기준을 지나다)
⊙
부치다 / 붙이다 : 부치다(편지·짐을 보내다, 전을 굽다)  vs  붙이다(맞닿아 떨어지지 않게 하다)
⊙
늘리다 / 늘이다 : 늘리다(수·양·부피·실력을 크게 하다)  vs  늘이다(본디보다 길이를 더 길게 하다)
