# 다다어휘

**목적**: 다다어휘 교재를 원본과 조판본으로 나눠 한 곳에 모아 둡니다. 이전에는 `다다어휘`와 `다다어휘(부교재)` 두 곳에 나뉘어 있었습니다.

**구성**
- `원본/`: 차시별 원본 HWP, 이미지, 워크북 PDF, 디자인 작업본 (이전 `다다어휘` 폴더)
- `부교재/`: 1호·2호 조판본, 디자인완성본, 답안지 (이전 `다다어휘(부교재)` 폴더)

**최신본 찾는 법**: 조판 최종본은 `부교재/1호/디자인완성본`, `부교재/2호/디자인완성본`에 있습니다. `.bak` 파일은 구버전입니다.

**주의**: 조판은 A4 한 장에 맞춥니다. 글자가 넘치지 않는지 확인합니다.
