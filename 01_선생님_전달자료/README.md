# 01_선생님_전달자료

**목적**: 김대표님이 선생님께 전달해 드리는 스킬과 자료를 모아 둡니다. 선생님은 읽기와 다운로드만 하시면 됩니다.

**주요 파일**
- `hanuri-teacher-assistant_파견팩.zip`: 선생님 전담 AI 스킬 원클릭 설치 패키지
- `카톡전송_미종샘_키티_개편패키지.txt`: 설치와 사용법 안내문
- `키티와_미종샘_소통가이드_만화.jpg`: 2컷 소통 가이드
- `한우리_필독도서목록_160선_최신본.xlsx`: 서식 정리된 필독도서 160선 목록

**최신본**: 같은 이름의 파일이 여러 개면 가장 최근 수정본을 씁니다. 목록은 이 폴더 기준으로 봅니다.

**주의**: 이 폴더의 파일은 김대표님이 관리합니다. 선생님이 수정하지 않도록 읽기 전용으로 두는 것을 권합니다.
