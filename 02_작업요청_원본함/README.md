# 02_작업요청_원본함

**목적**: 선생님이 AI나 김대표님께 작업을 맡길 때 원본 파일을 넣는 곳입니다.

**현재 상태**: 비어 있음 (작업 요청 없음).

**사용 방법**
- 선생님이 원본 파일을 여기에 넣습니다.
- 파일명 앞에 날짜를 붙입니다. 예: `20261023_다다어휘1호.html`, `20261023_세계지리_원문.pptx`
- 작업이 끝나면 결과물은 [03_완성본_인쇄출력함](../03_완성본_인쇄출력함/README.md)으로 갑니다.

**권한 (원본 안내 기준)**: 선생님이 업로드, 김대표님·AI는 읽기와 복사만 합니다.
