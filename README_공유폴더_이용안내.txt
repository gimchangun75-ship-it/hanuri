[ 01_선생님_전달자료 ]  (권한: 김대표님·키티 편집 / 선생님 읽기·다운로드 전용)
- 김대표님이 선생님께 전달해 드리는 최신 스킬 및 자료 모음입니다.
  * hanuri-teacher-assistant_파견팩.zip : 키티 전담 스킬 원클릭 설치기
  * 카톡전송_미종샘_키티_개편패키지.txt : 설치 및 사용법 안내문
  * 키티와_미종샘_소통가이드_만화.jpg : 2컷 웹툰 소통 가이드
  * 한우리_필독도서목록_160선_최신본.xlsx : 서식 정렬된 160권 도서목록 (160권 완제본)

[ 02_작업요청_원본함 ]  (권한: 선생님 파일 업로드 / 김대표님·키티 읽기·수렴 전용)
- 선생님께서 키티나 김대표님에게 작업을 요청하실 원본 파일을 넣어두시는 곳입니다.
  * 예: "슬라이드 9번 캡션 지워줘" 할 PPT 파일
  * 예: "A4 2페이지로 예쁘게 조판해줘" 할 다다어휘 HTML/한글 파일
  * 예: "열 너비랑 서식 정렬해줘" 할 도서목록 엑셀 파일
  💡 [권장 파일명]: 파일이 덮어써지는 것을 방지하기 위해 날짜를 붙여주시면 좋습니다.
     (예: 20261023_세계지리_원문.pptx, 20261023_다다어휘1호.html)

[ 03_완성본_인쇄출력함 ]  (권한: 김대표님·키티 편집 / 선생님 읽기·인쇄 전용)
- 작업이 완료되어 선생님이 즉시 인쇄하거나 수업에 쓰실 수 있는 최종본이 저장됩니다.
  * 2쪽 완결로 예쁘게 줄 바꿈 된 다다어휘 A4 활동지
  * 캡션이 핀포인트로 깔끔하게 삭제된 수업용 PPT
  * 학생용 문제지와 교사용 정답지가 분리된 시험지
  💡 [완성본 파일명 규격]: 날짜_과정명_버전 형식으로 안전 보관됩니다.
     (예: 20261023_세계지리_슬라이드9_캡션제거완료.pptx)

[ 00_한우리_소개및연구자료 ]  (권한: 김대표님·키티 편집 / 선생님 읽기 전용)
