꼭지 01 아름다운 흉터 | 이청준 (12~14쪽)
1. O : 본문 첫 문장에 "세 종류의 흉터가 선명하게 남아 있다"고 밝힘.
2. O : 초등 1학년 소풍 전날 토방 아래 누렁이 목을 조르다 왼손을 물려 생긴 상처임.
3. X : 초등학교 5학년 때 남의 산에 나무하러 갔다가 도둑 톱질 끝에 쓰러지는 나무를 피하려다 마른 가지에 찍힌 흉터임.
4. O : 고등학교 때까지 방학마다 고향 집에서 논밭걷이와 푸나무 낫질을 하다 왼손 검지와 장지에 상처가 더해짐.
5. X : 도회지 아이들의 희고 깨끗한 손에 비해 일로 거칠어지고 흉터가 많아 큰 부끄러움거리가 되었음.
6. O : 직장의 나이 든 선배가 자신의 상처 많은 손을 보여주며 건넨 따뜻한 말 한마디로 인식이 변화됨.
7. X : "어려운 시절을 힘차게 살아 냈구먼"이라며 깊이 이해하고 위로해 줌.
8. O : 상처의 흔적이야말로 우리 삶의 단단한 마디요 숨은 값이라고 서술함.
9. X : 오직 나만의 자랑거리로 삼지 말고 자신의 삶을 겸손하게 되돌아보는 거울로 삼아야 한다고 강조함.
10. O : "자기 흉터엔 겸손한 긍지를, 남의 흉터엔 위로와 경의를, 흉터 많은 우리 삶엔 사랑의 찬가를"이라며 마무리함.
꼭지 02 어느 날 자전거가 내 삶 속으로 들어왔다 | 성석제 (16~19쪽)
1. X : 초등학교 때처럼 걸어서 다니기 힘든 거리였고, 버스나 자가용도 없었음.
2. O : 고향이 분지 지형이라 평탄하여 집집마다 자전거가 흔했음.
3. O : 큰집에서 짐받이가 크고 무거운 농업용 자전거를 빌려 연습함.
4. X : 운동 신경이 둔하다는 핑계로 타지 않았으나 다른 아이들이 부럽기도 했음.
5. X : 오전에 사람이 없는 운동장으로 가서 시멘트 계단 옆에서 출발 연습을 함.
6. O : 바퀴가 두 번 구르기도 전에 넘어지기를 수백 번 거듭하며 멍이 들고 피부가 벗겨짐.
7. O : 50미터쯤 되는 오르막에서 내리막을 달려 내려가면 쉽게 탈 수 있을 거라 생각함.
8. O : 내리막 아래 휘어진 길 정면에는 도랑과 거름용 분뇨 똥통이 있었음.
9. X : 도랑과 똥통 옆을 무사히 통과하여 읍내 길을 신나게 내달림.
10. O : "일단 안장 위에 올라선 이상 계속 가지 않으면 쓰러진다"는 중요한 삶의 원리를 깨달음.
꼭지 03 부딪치면서 배워요 | 오소희 (22~26쪽)
1. O : 에티오피아에서 돌아온 뒤 아프리카 여행기를 읽고 싶어 하는 친척 동생의 사연 메일을 받음.
2. X : 당시 점자책이나 오디오북이 없어 작가가 직접 가서 읽어 주겠다고 답장을 보냄.
3. O : 수빈과 희원은 당시 중학교 2학년 시각 장애 소년들이었음.
4. X : 수빈은 덩치가 크고 진중했고, 희원은 작고 유쾌했음 (성격이 뒤바뀜).
5. O : 교실 정리 시간이 되자 수빈이가 '제일 먼저' 불을 끔.
6. X : 아이들은 암흑 속에서도 매우 능숙하고 자연스럽게 블라인드를 내리고 책걸상을 정리함.
7. O : 형광등은 아이들이 아니라 오직 글쓴이 자신만을 위해 켜져 있었음을 비로소 깨달음.
8. O : 새로운 공간에선 어떻게 하냐고 묻자 희원이가 "부딪치면서 배워요"라고 명쾌하게 대답함.
9. X : 1~2초간 숨이 멎을 정도로 깊은 감동과 신선한 깨달음을 얻음.
10. O : 온몸을 내던져 부딪치며 배우는 삶의 태도를 본받아 중년의 삶을 살아가겠다고 다짐함.
꼭지 04 괜찮아 | 장영희 (28~32쪽)
1. O : 서울 동대문구 제기동의 작은 한옥에서 유년 시절을 보냄.
2. X : 어머니는 방에만 틀어박혀 책 읽는 것을 싫어하셔서 방석을 깔아 대문 앞 계단에 앉히셨음.
3. O : 다른 뛰어노는 놀이는 못 했지만 공기놀이에는 직접 참여함.
4. X : 심판, 가방 보관, 술래잡기 숨을 곳 미리 알려주기 등 친구들이 소외되지 않도록 역할을 만들어 줌.
5. O : 깨엿 장수 아저씨가 리어카를 두고 돌아와 깨엿 두 개를 주며 "괜찮아"라고 말함.
6. O : 세상은 그런대로 살 만한 곳이고 좋은 친구들과 선의와 사랑이 있음을 마음에 새김.
7. O : 뚱뚱한 친구를 위해 "얜 골키퍼를 시키면 우리 함께 놀 수 있잖아!"라며 함께 어울림.
8. X : 2002년 월드컵 4강전에서 독일에게 패배했을 때 관중들이 외친 위로와 격려였음.
9. O : 용서, 격려, 나눔, 부축, 그리고 다시 시작할 수 있다는 희망의 속삭임임.
10. X : 세상살이가 만만치 않고 뜻대로 풀리지 않을 때 마음속에서 떠올리는 말임.
꼭지 05 천 원 | 손성주 (34~36쪽)
1. X : 학교생활도 잘하고 친구들과 즐겁게 지내다 오던 길에 이유 없이 극심한 피로와 우울함이 찾아옴.
2. O : 몸이 무겁고 지쳐 집에 다 와서 보건소 앞 벤치에 털썩 주저앉음.
3. O : 지나가던 두 할머니 중 보라색 잠바를 입으신 할머니가 다가오심.
4. X : 가방에서 주섬주섬 꼬깃꼬깃한 1,000원짜리 지폐를 꺼내 주심.
5. O : 딱 나만 한 손녀가 있어 손녀 생각이 나서 주는 것이라며 받게 하심.
6. X : 거절하는 것이 예의가 아닌 것 같아 감사하고 찡한 마음으로 받음.
7. O : 지나가는 사람들의 시선 때문에 훌쩍이며 눈물을 닦았고 큰 위로를 받음.
8. X : 맛있는 걸 사 먹지 않고 힘들 때 보고 힘내기 위해 고이 간직함.
9. O : 현재도 방 책장 위 지갑 안에 소중히 보관하고 있음.
10. O : 번아웃이 오거나 지칠 때마다 지갑을 쥐어 보며 힘을 냄.
꼭지 06 선물 | 성석제 (38~40쪽)
1. X : 정착민, 농경의 세계여서 식구끼리 선물을 주고받는 것은 상상조차 못 했음.
2. O : 호떡 종이 봉지에 들어갈 정도로 작은 강아지를 점퍼 속에 넣어 오심.
3. X : 중학교 2학년 때 서울로 전학 온 시기였음.
4. O : 일평생 처음 선물을 주시던 겨울밤, 아버지에게서 술 냄새가 났음.
5. O : 가축은 집 안에 들이지 않는 가풍에 따라 현관 밖 상자에 둠.
6. X : 글쓴이 외에는 아무도 일어나지 않았고 아버지는 코를 골며 주무심.
7. O : 배가 고파 우는 줄 알고 저녁에 남겨둔 백설기와 물을 갖다 줌.
8. X : 너무 어려서 백설기를 전혀 먹지 못하고 물도 마시지 않았음.
9. O : 머리를 쓰다듬자 울음을 그쳤고, 글쓴이는 내복 바람으로 밤새 곁을 지키며 날을 샜음.
10. O : 아버지는 강아지를, 나는 백설기를 선물했고 강아지는 내게 '연민의 감정'을 선물함.
꼭지 07 열보다 큰 아홉 | 이문구 (42~45쪽)
1. O : 열은 십진법에서 제일 먼저 꽉 찬 수이며 이룰 것을 이룬 완전한 수임.
2. O : '십상(十成) 좋다'의 십상은 열 십과 이룰 성에서 유래함.
3. X : 조상들은 오랜 옛날부터 열보다 아홉을 더 사랑했음.
4. O : 십만리장천이 아니라 '구만리장천(九萬里長天)'이라고 표현함.
5. X : 9층 탑은 부지기수로 많아도 10층 탑은 보기 어렵다고 밝힘.
6. O : 음력 9월 9일 중양절(중굿날)을 1,000년 넘게 명절로 쇠었음.
7. X : 완벽함을 기대하지 않았고, 세상에 완전한 것이 없음을 알았기 때문임.
8. X : "모든 기록은 깨어지기 위해서 있다"는 말처럼 해마다 기록이 깨지므로 계속 개정 발간됨.
9. O : 아홉은 여유가 있고 미래의 꿈과 다음 단계의 가능성을 열어두는 수임.
10. O : 한창 자라는 중학생들에게 부족하고 어설픈 것이 정상이니 아홉의 마음가짐을 갖길 권함.
꼭지 08 탑차를 끄는 사계절의 산타 | 김지원 (48~53쪽)
1. O : 7년 동안 매일 밤 아버지가 가져온 운송장의 숫자를 컴퓨터에 입력함.
2. O : 12자리 숫자로 된 운송장을 하루 약 200장씩 처리함.
3. X : 우산 대신 두꺼운 박스에 든 물건이 젖을까 봐 품에 꼭 안고 비를 맞으며 달림.
4. O : 차에 늘 있던 소보로빵을 건네주며 따뜻하게 챙겨 주심.
5. O : 진한 붉은 계열 교복 재킷에 대고 빗물에 젖은 송장을 빳빳하게 말림.
6. X : 스마트폰은 잘 다루지 못했으나 주소와 현관 특징, 부재 시 보관 장소를 머릿속으로 완벽히 기억함.
7. O : 기사는 여러 개를 배달하지만 받는 사람은 오직 그 하나를 기다리므로 각별하다고 생각함.
8. X : 글쓴이와는 띠동갑 차이가 나고 서로에겐 연년생인 어린 동생들이었음.
9. O : 루돌프 대신 탑차를 몰며 1년 365일 선물을 전하는 사계절의 산타임.
10. X : 집 앞에 도착하면 꼭 전화를 걸어 "누가 안 가져가게 잘 넣어 둘게요"라고 안심시켜 줌.
꼭지 09 할아버지의 엄마 나무 | 한아리 (56~58쪽)
1. X : 낡은 그림인 줄 알았으나 빛바랜 '증조할머니의 사진'이었음.
2. O : 이북 5도민 단체에서 나눠준 황해도 연백의 고향 흙이었음.
3. O : 열세 살에 가족과 헤어져 홀로 남쪽에 남겨진 실향민이심.
4. X : 열세 살 할아버지를 먼저 남쪽에 데려다 놓고 가족을 데리러 북으로 가신 사이 분단됨.
5. O : 흙을 만지고 냄새 맡으며 엄마를 품에 안듯 눈물을 흘리심.
6. O : 통에 든 고향 흙을 마당 구석 화단에 넣고 함께 식재함.
7. O : 증조할머니가 생전에 좋아하셨던 철쭉을 심음.
8. X : 글쓴이가 "할아버지, 우리 이 나무 이름을 '엄마'라고 지어요"라고 제안함.
9. X : "그거 좋다"라며 손녀를 따뜻하게 안아 주심.
10. O : 활짝 핀 철쭉꽃을 보며 할아버지가 슬픔을 위로받길 진심으로 소망함.
꼭지 10 사막을 같이 가는 벗 | 양귀자 (60~63쪽)
1. O : 학년과 반이 바뀌어 친구들과 헤어지는 신학기를 유별나게 싫어함.
2. X : 낯가림으로 혼자 외톨이가 된 것 같아 가슴이 써늘해지고 도망가고 싶어 했음.
3. O : 서먹한 짝과 밥알 씹는 소리까지 들으며 먹는 점심시간이 몹시 거북(무렴)했음.
4. O : 방학 때쯤이면 외로움을 덜어줄 단짝 친구를 발견하곤 했음.
5. X : 시기, 미움, 속임이 가득한 거친 파도의 망망대해 같은 황폐한 세상살이였음.
6. O : 고난의 인생길에서 영혼의 교류를 나눌 따뜻한 동반자가 절실함을 강조함.
7. O : 실패한 친구를 위해 직장을 그만두고 온 가족과 함께 시골로 내려가 땅을 일굼.
8. X : 냉혹한 세상에 맞서 힘을 합쳤으니 든든하다며 서로 깊이 신뢰함.
9. O : 친구 없는 삶은 무서운 사막이자 증인 없이 죽는 일이라는 경구를 깊이 새김.
