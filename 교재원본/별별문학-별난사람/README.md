# 별별문학-별난사람

**목적**: 별별문학 교재의 원본, 최종 PDF, 발표 자료, 필독서를 보관합니다. 가장 많은 파일(약 110개)이 있는 폴더입니다.

**하위 폴더**
- `별별문학 교재(원본)/`: 차시별 원본 PDF (2-1차시, 2-2차시 등)
- `PDF(최종)/`: 최종 PDF (개념 시·소설·수필·고전, 추가 수록 도서, 표지)
- `발표/`: 발표 자료 PPTX와 PDF (별별문학 1호, 2-2차시 수필)
- `필독서/`: 필독서 자료
- `004.개념 5분 테스트(미종 테스트).hwp`: 5분 테스트 원본

**최신본 찾는 법**: 파일명에 `최종`, `FIN`이 있는 것을 먼저 봅니다. 원본은 `(원본)` 폴더에 있습니다.
