# 교재원본

**목적**: 과목과 교재별 원본 자료를 모아 둡니다. 정리 전에는 루트 폴더에 흩어져 있던 교재를 이곳으로 옮겼습니다.

**하위 폴더**
- `수업 PDF/`: 수업용 PDF, PPT, HWP 모음 (가장 큰 폴더)
- `똑똑한국사/`: 한국사 교재 PDF (1호, 2호)
- `별별문학-별난사람/`: 별별문학 교재 원본, 최종 PDF, 발표 자료
- `똑독해(원희샘)/`: 통합과학 수업 자료
- `비룡소 중등/`: 비룡소 중등 워크북
- `세계사(사직중)/`: 사직중 세계사 단원 자료
- `세계사통사ppt(미종샘)/`: 세계사 통사 차시별 PPT
- `진주/`: 번호가 붙은 지문 HWPX
- `토론/`: 토론 스크립트
- `도서선정/`: 월별 필독서 추천 자료
- `수필1_5분테스트/`: 수필 5분 테스트 (선생님용, 학생용)
- `카폭 프로필/`: 안내문과 프로필 이미지 (돌보장 프로필 이미지 포함)
