# 도서선정

**목적**: 어휘리더 1 필독서를 월별로 추천한 자료를 모아 둡니다.

**주요 파일**
- `2022년 12월`~`2024년 4월` 어휘리더 필독서 추천 HWP (이미종 작성, 약 20개)
- `어휘리더 필독서 추천 양식.hwp`: 추천서 양식
- `도서선정 연구원 활동 방법.hwp`: 활동 안내
- `광화사.hwp`: 도서 검토 자료

**파일명 규칙**: `연도 월 어휘리더1 필독서 추천(이미종).hwp` 형식입니다. 새 달 자료도 같은 형식으로 만듭니다.

**주의**: 파일명에 띄어쓰기가 일정하지 않습니다(예: `2023년 9월 어휘리더 1 필독서`). 정렬이나 검색에 주의합니다.
