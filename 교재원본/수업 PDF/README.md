# 수업 PDF

**목적**: 수업에 바로 쓰는 PDF, PPT, HWP 파일이 섞여 있는 폴더입니다. 용량이 가장 큰 폴더(약 1.1GB)입니다.

**주요 파일 종류**
- PDF: 돈키호테, 동물농장, 빛속으로, 열하일기 등 도서 수업 자료
- PPTX: 마지막 거인, 미래가 온다(미래식량) 등
- HWP: 차시별 수업 자료 (논리, 돈키호테, 광화사 등)
- `.show`: 멸종을 선택하지 마세요 (용량 약 120MB)
- `시윤유하/`: 시윤유하 작성 교재 PDF 모음

**주의**
- 파일 이름에 특수문자와 띄어쓰기가 많습니다.
- 용량이 큰 파일(예: `이순신의 마음속 기록, 난중일기.pptx` 460MB)은 복사할 때 시간이 걸립니다.
