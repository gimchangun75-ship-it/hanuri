# 한우리_자동로그인_도우미

**목적**: 한우리 에듀넷과 수업지원시스템 로그인 화면에서 입력을 돕는 Chrome 확장 프로그램입니다. 버전 1.3.0.

**주요 파일**
- `manifest.json`: 확장 프로그램 설정 (적용 사이트 지정)
- `content.js`: 로그인 화면에 입력 칸과 버튼을 추가하는 스크립트
- `hanuri-teacher-assistant_파견팩/`: 파견팩 사본

**주의**
- 이 확장은 브라우저 로컬 저장소에 로그인 정보를 보관합니다. 저장된 값은 이미종 선생님 본인 계정이므로 열람하거나 공유하지 않습니다.
