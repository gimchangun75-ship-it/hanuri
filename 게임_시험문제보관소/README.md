# 🏛️ [한우리] 워드 나이츠 시험문제 보관소 (Quiz Bank Repository)

이 디렉터리는 **『워드 나이츠 : 문맥의 수호자』** 게임과 실시간 연동되는 한우리 교재/시험문제의 영구 보관소입니다.  
선생님이 한글(HWPX), PDF, 엑셀 문제를 이곳에 넣으면 AI 비서가 즉시 게임용 문제 데이터로 변환하여 게임 엔진에 탑재합니다.

---

## 📂 폴더 구조 및 규격
* **`다다어휘_1호_1차시.json`**: 다다어휘 1호 연동 문제 팩
* **`다다어휘_2호_1차시.json`**: 다다어휘 2호 관용구/속담 문제 팩
* **`월간필독서_모의고사.json`**: 월간 도서 문해력/추론 문제 팩

## 🎯 게임 + 학습 (에듀테인먼트) 시너지 핵심 전략
1. **아이들**: "공부/시험"이 아니라 **"브롤스타즈 보스 레이드"**로 인식하여 스스로 문제를 풀고 싶어 안달 남.
2. **선생님**: 수업 시작 5분 전, 진도에 맞는 JSON/시험지 파일만 선택하면 **준비 시간 0초 만에 교실 분위기 장악**.
3. **학부모**: 게임 종료 후 자동 발송되는 **"오늘의 전설 어휘 리포트"**로 학원 만족도 및 재등록률 극대화!
