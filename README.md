## 공통 규칙

- 최신본을 찾을 때는 파일명 끝의 `(디자인)`, `최종`, `완성본` 같은 표시와 `디자인완성본` 폴더를 먼저 봅니다.
- `.bak`, `temp_`, `_백업` 같은 파일은 구버전이거나 임시 파일입니다.
- 파일을 옮기거나 지울 때는 해당 폴더의 `README.md`와 이 목차도 함께 고칩니다.
- 로그인 정보나 개인 계정이 들어 있는 파일은 공유하지 않습니다.
