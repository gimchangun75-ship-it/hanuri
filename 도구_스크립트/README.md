# 도구_스크립트

**목적**: 파일 변환, 자동화, 작업 보조에 쓰는 도구와 스크립트를 모아 둡니다.

**주요 파일**
- `tools/`: HWP→PDF 변환 도구 (사용설명서는 `tools/HWP-to-PDF-Pack/(0) 사용설명서.txt`)
- `hanuri-teacher-assistant_파견팩/`: 선생님 PC에 설치하는 AI 스킬 패키지 (루트 사본)
- `crop.ps1`: 이미지 자르기 스크립트

**주의**
- 이 폴더로 옮긴 뒤에도 스크립트 안에 `D:\한우리`, `F:\한우리` 같은 경로가 고정되어 있을 수 있습니다. 실행 전에 경로를 확인합니다.
- `C드라이브_분할_D드라이브_생성.bat`은 디스크 파티션을 바꾸는 파일입니다. 실행하지 않습니다. 현재는 루트에 그대로 두었습니다.
- 크롤러, 동기화 스크립트, 대화방 기록, 자동로그인 도우미는 경로가 고정되어 있어 이번 정리에서 옮기지 않았습니다.
