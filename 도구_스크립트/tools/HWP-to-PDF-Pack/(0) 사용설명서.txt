================================================================================
 [천하무적] 아래한글(HWP / HWPX) -> PDF 변환 패키지 사용설명서
================================================================================

본 프로그램은 아래한글 문서(.hwp, .hwpx)를 표, 글꼴, 수식, 서식 깨짐 없이
100% 원본 그대로 완벽하게 PDF로 변환해 주는 원클릭 도구입니다.

--------------------------------------------------------------------------------
 [가장 쉬운 3가지 사용 방법]
--------------------------------------------------------------------------------

1. [방법 1] 마우스로 끌어다 놓기 (가장 추천)
   - 변환하고 싶은 한글 파일(들)을 마우스로 잡아서
   - "(1) 한글PDF변환_여기로_파일끌어놓기.bat" 아이콘 위에 올려놓으시면 끝납니다!

2. [방법 2] 현재 폴더 전체 한 방에 변환하기
   - 이 폴더 안에 있는 모든 한글 문서를 다 바꾸고 싶을 때는
   - "(2) 현재폴더_전체일괄변환.bat" 파일을 그냥 더블클릭하시면 됩니다.

3. [방법 3] 마우스 우클릭 메뉴로 변환하기 (고수 추천)
   - "(3) 우클릭_PDF변환_메뉴추가.bat"을 1회 실행해 두시면,
   - 앞으로 윈도우 탐색기에서 아무 한글 파일이나 마우스 우클릭했을 때
     [PDF로 즉시 변환] 메뉴가 생깁니다!
   - (메뉴를 없애고 싶을 때는 "(4) 우클릭_PDF변환_메뉴삭제.bat"을 누르면 됩니다.)

--------------------------------------------------------------------------------
 [참고 사항]
--------------------------------------------------------------------------------
- 컴퓨터에 한컴오피스(한글) 및 Python이 설치되어 있어야 합니다.
- 필요한 라이브러리(pywin32)는 최초 실행 시 알아서 자동 설치됩니다.
- 한글 프로그램의 보안 경고창("접근 허용")은 엔진 내부에서 100% 자동으로 차단됩니다.
- 변환된 PDF 파일은 원본 한글 파일과 동일한 위치에 생성됩니다.
